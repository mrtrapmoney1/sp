Lotus DBF Field Mapping

The following fields are exported to the Lotus-compatible DBF format:

Customer Info
  • INVOICE - Invoice number
  • LASTNAME - Last name
  • FIRSTNAME - First name
  • ADDRESS - Street address
  • CITY - City
  • STATE - State (2 letters)
  • ZIP - ZIP code
Contact & Location
  • PHONE - Primary phone
  • PHONE2 - Alt phone
  • LOCATION - Service location
  • TICLOC - Ticket location
  • BTADDRESS - Call number (SA-*)
  • DLRINVOICE - Case/dealer invoice
  • ACCESSOR - Warranty type
Product & Service
  • SERVICEREQ - Service request/problem
  • MAKE - Brand/manufacturer
  • TYP - Product type
  • MODEL - Model number
  • SERIAL - Serial number
  • DATEIN - Date received
  • DATEPUR - Purchase date
