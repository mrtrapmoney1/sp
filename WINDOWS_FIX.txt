  - dbfread instead of dbf (pure Python, no compilation)
  - Loosened version constraints for compatibility

  - Changed: from dbf import Table
  - To: from dbfread import DBF
  - All DBF reading code updated

IF STILL FAILS (Alternative Methods):
─────────────────────────────────────────────────────────────────

METHOD 1: Install Pre-built Wheels Only
────────────────────────────────────────
pip install --only-binary :all: pandas numpy

Then:
pip install -r requirements.txt


METHOD 2: Downgrade Python Version
────────────────────────────────────────
Python 3.14 is very new. Consider using Python 3.11 or 3.12:
- Download Python 3.11 or 3.12 from python.org
- Reinstall in C:\Python311 or C:\Python312
- Use that version instead


METHOD 3: Install Visual Studio Build Tools (Advanced)
────────────────────────────────────────────────────────
1. Download "Build Tools for Visual Studio 2022"
   https://visualstudio.microsoft.com/downloads/

2. Install with "Desktop development with C++"

3. Retry: pip install -r requirements.txt

This takes ~6GB disk space and 30-60 minutes.


METHOD 4: Use Windows Subsystem for Linux (WSL)
────────────────────────────────────────────────────────
1. Install WSL: wsl --install
2. Open Ubuntu
3. Install Python: sudo apt install python3-pip
4. Navigate to your folder
5. pip install -r requirements.txt
6. python app.py

WHAT CHANGED IN CODE:
─────────────────────────────────────────────────────────────────

requirements.txt:
- OLD: dbf==0.99.1 (requires C compiler)
- NEW: dbfread>=2.0.7 (pure Python)

- OLD: pandas==2.1.4 (no wheels for Python 3.14)
- NEW: pandas>=2.2.0 (has pre-built wheels)

app.py:
- OLD: from dbf import Table
- NEW: from dbfread import DBF

- OLD: table = Table(dbf_path)
       table.open()
       records = []
       for record in table:
           ...
       table.close()

- NEW: table = DBF(dbf_path, load=True, ignore_missing_memofile=True)
       records = list(table)

All functionality remains the same. Just using a different DBF library.
